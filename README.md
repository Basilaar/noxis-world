# Noxis World

Базовый шаблон приложения в тематике **D&D** для дальнейшей разработки.
Тёмная тема, модульный SCSS, адаптивная вёрстка и сказочная долина на фоне — как вход в новый мир.

## Стек

| Технология | Версия | Роль |
|------------|--------|------|
| **React** | 19 | UI-библиотека |
| **Next.js** | 16 (App Router) | Фреймворк, роутинг, рендеринг |
| **SCSS (Sass)** | — | Стилизация, модульные `*.module.scss` |
| **TypeScript** | 5.7 | Типизация |
| **lucide-react** | — | Иконки (бургер / крестик) |

### Про «React Router»

В экосистеме Next.js **не используют** отдельную библиотеку `react-router`.
Стандартное и самое популярное среди разработчиков решение — встроенный
**App Router** от Next.js: маршрутизация основана на файловой структуре папки
`app/`, работает с серверными компонентами React 19 из коробки и не требует
дополнительных зависимостей. Именно он используется в этом проекте.

## Архитектура

Проект следует конвенциям **Next.js App Router** с разделением на слои:
маршруты (`app/`), переиспользуемые компоненты (`components/`), общая логика
(`lib/`) и глобальные стили/токены (`styles/`).

```
app/                      # Маршруты (App Router). Одна папка = один URL
├── layout.tsx            # Корневой layout: шрифты, <html>, метаданные, AppShell
├── globals.scss          # Сброс стилей + CSS-переменные тёмной темы
├── page.tsx              # "/"        → General
├── page-1/page.tsx       # "/page-1"  → Page 1
└── page-2/page.tsx       # "/page-2"  → Page 2

components/
├── layout/               # Каркас приложения
│   ├── AppShell.tsx      #   объединяет фон + навигацию + слот страницы
│   ├── Background.tsx    #   фиксированная долина D&D + затемнение
│   ├── Navbar.tsx        #   десктоп/планшет: верхняя навигация ('use client')
│   └── MobileNav.tsx     #   мобильные: бургер снизу справа + меню снизу ('use client')
└── page/
    └── PageSection.tsx   # Переиспользуемый шаблон страницы (заголовок + карточка)

lib/
└── navigation.ts         # Единый источник правды по пунктам меню (NAV_ITEMS)

styles/                   # Общие SCSS-ресурсы (без вывода CSS)
├── _variables.scss       #   токены: брейкпоинты, размеры, z-index
└── _mixins.scss          #   медиа-хелперы (up/down), стекло, focus-ring

public/images/
└── dnd-valley.png        # Сгенерированный фон — сказочная долина
```

### Ключевые решения

- **App Router + серверные компоненты по умолчанию.** Страницы и `AppShell`
  рендерятся на сервере. Клиентскими (`'use client'`) сделаны только те
  компоненты, которым нужна интерактивность или хуки — `Navbar` (подсветка
  активного пути через `usePathname`) и `MobileNav` (состояние открытия меню).

- **Модульный SCSS.** Каждый компонент имеет собственный `*.module.scss` —
  классы изолированы (нет конфликтов имён), стили лежат рядом с компонентом.
  Общие переменные и миксины вынесены в `styles/` и подключаются через
  `@use`. Путь к ним настроен в `next.config.mjs` (`sassOptions.loadPaths`),
  поэтому импортируются коротко: `@use 'variables' as *`.

- **Тёмная тема на CSS-переменных.** Runtime-токены (цвета, шрифты) объявлены
  в `:root` в `globals.scss` с `color-scheme: dark`. Build-time значения
  (брейкпоинты, z-index) — это SCSS-переменные в `_variables.scss`.
  Разделение позволяет при желании добавить светлую тему без переписывания
  логики.

- **Единый источник навигации.** `lib/navigation.ts` экспортирует `NAV_ITEMS`;
  и десктопное, и мобильное меню строятся из него — добавление пункта в одном
  месте обновляет обе навигации.

- **Адаптивность (mobile-first).** Брейкпоинт `768px` разделяет два режима
  навигации: выше — верхний navbar, ниже — плавающая бургер-кнопка в правом
  нижнем углу и выезжающее снизу меню (bottom sheet). Учтены `env(safe-area-inset-*)`
  для устройств с вырезами, блокировка скролла и закрытие по `Esc`.

- **Типографика.** Два шрифта через `next/font/google`: **Cinzel**
  (заголовки, «фэнтезийный» акцент) и **Inter** (текст). Подключаются как
  CSS-переменные — без layout shift.

- **Доступность и безопасность.** Семантические теги (`header`, `main`, `nav`),
  ARIA-атрибуты (`aria-current`, `aria-expanded`, `aria-controls`),
  focus-ring, поддержка `prefers-reduced-motion`. В `next.config.mjs` заданы
  базовые security-заголовки.

## Запуск локально

```bash
pnpm install
pnpm dev      # http://localhost:3000
```

```bash
pnpm build    # продакшн-сборка
pnpm start    # запуск собранного приложения
```

## Как добавить страницу

1. Создать `app/<slug>/page.tsx` и отрендерить в нём `<PageSection>`.
2. Добавить пункт `{ label, href }` в `NAV_ITEMS` в `lib/navigation.ts`.

Навигация (десктоп и мобайл) подхватит новую страницу автоматически.
